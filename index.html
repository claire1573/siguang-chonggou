3问卷设计逻辑

问卷不是随意的信息收集表，而是为计算引擎量身定制的"数据采集契约"。每一道题都能在下游公式里找到用途，用不到的题一律不设。

三要三不要

  • 要可计算：答案必须能转成数值或可枚举类别
  • 要低负担：5 分钟内完成，多用选择少用填空
  • 要可校验：设交叉验证，识别前后矛盾的回答
  • 不要专业术语：问"有高血压吗"而非"血压分级"
  • 不要过度精确：用频率代替克数，用户填得出
  • 不要评判感：措辞中性，避免被指责
模块采集维度下游用途
基础信息性别/年龄/身高/体重计算 BMR 与 TDEE
健康禁忌慢病史/过敏原触发安全硬约束，最高优先级
生活习惯活动量/应酬修正活动系数，识别应酬型用户
饮食偏好主食/高危餐次/做饭条件/忌口决定食谱的可接受度与可执行度
目标动机减重量/期限/动机设定减重速率上限，差异化激励

4计算推导逻辑

从答案到食谱，是一条五步算法链路，每一步都有数学依据，且可解释——用户能看到"为什么是这些"。

① 能量基线BMR → TDEE

② 能量缺口安全区间约束
→
③ 三大营养素蛋白/脂肪/碳水
→
④ 约束过滤硬/软/偏好
→
⑤ 食谱装配组合优化

步骤一：能量基线

男：BMR = 10×体重 + 6.25×身高 − 5×年龄 + 5
女：BMR = 10×体重 + 6.25×身高 − 5×年龄 − 161
TDEE = BMR × 活动系数 (久坐1.2 / 轻度1.375 / 中度1.55 / 高度1.725)

采用 Mifflin-St Jeor 公式，被美国营养与饮食学会等主流机构推荐。

步骤二：能量缺口（不是越大越好）

每日目标摄入 = TDEE − 缺口　缺口上限 500~750 kcal
  • 下限保护：男 ≥1500 kcal、女 ≥1200 kcal，避免饿出代谢损伤
  • 目标纠偏：目标过激进时自动回落到安全速率并解释原因
  • 慢病人群：缺口进一步收窄，优先营养密度

步骤三：三大营养素分配

营养素占比热量中年减重考量
蛋白质25-35%4 kcal/g保护肌肉、增强饱腹、热效应高
脂肪20-30%9 kcal/g必需脂肪酸，中年代谢慢不宜高
碳水35-50%4 kcal/g优先低GI、高纤维复合碳水

步骤四：三层约束过滤

层级类型示例处理
L1硬约束(安全红线)糖尿病→排高GI；痛风→排高嘌呤；过敏→排过敏原直接剔除
L2软约束(健康建议)高血压→控钠；脂肪肝→控酒精果糖尽量满足
L3偏好加权不爱吃→权重0；爱吃→提高匹配影响排序

步骤五：食谱装配（组合优化）

min |实际热量−目标| + λ₁|蛋白偏差| + λ₂|碳水偏差| + λ₃|脂肪偏差|

在"热量接近、营养达标、用户爱吃、能做得了"之间寻找最优平衡，并内置一键换菜替代规则。

如何带来更好效果与体验

  • 保肌减脂：偏高蛋白，减脂肪不减肌肉
  • 慢病友好：硬约束兜底，减肥不伤身
  • 渐进改变：粗粮替换、减盐"温水煮青蛙"
  • 防反弹：识别高危餐次，针对性控损
  • 匹配现实：按做饭条件给能落地的菜
  • 可解释：每份食谱附"为什么这样配"
