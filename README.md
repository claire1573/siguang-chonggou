# 食光重构 · 中年个性化减肥食谱推荐系统

面向中年人群的个性化减肥食谱推荐系统。通过问卷采集用户信息，经科学计算推导出个性化食谱。

## 功能

- 填写问卷（基础信息 / 健康禁忌 / 生活习惯 / 饮食偏好 / 目标动机）
- 实时计算引擎（BMR → TDEE → 能量缺口 → 三大营养素 → 约束过滤 → 食谱装配）
- 个性化食谱输出（含推导过程与"为什么"解释）
- 设计逻辑说明（问卷设计逻辑 + 计算推导逻辑 + 参考标准）

## 技术

纯前端静态站点，单文件 `index.html`，无后端依赖，任何人打开即可使用。

## 本地运行

直接用浏览器打开 `index.html` 即可，无需任何服务器。
